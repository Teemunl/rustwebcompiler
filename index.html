Rust-like subset compiler

This is a custom compiler for a small Rust-inspired language, not the official rustc. It compiles supported syntax into WebAssembly and runs it in your browser. Edit and run again to hot-swap changed functions.

Supported subset

Functions, i32, bool, (), String, &str, let/let mut, arithmetic and comparisons, &&/||, if/else, while, loop, for i in a..b and a..=b, break/continue/return, and println!/print! with {}. String values can be concatenated with +; both string types use the compiler's simple interned-string representation, without Rust ownership or borrowing semantics. "text".repeat(i32) is supported as a print argument. Structs, general references and borrow checking are not supported yet. Integer overflow wraps instead of panicking.
